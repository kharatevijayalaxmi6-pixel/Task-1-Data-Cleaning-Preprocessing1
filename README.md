# Task 1: Data Cleaning and Preprocessing

## Objective
To understand and perform data cleaning and preprocessing using Python.

## Dataset
Titanic Dataset

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Steps Performed
1. Loaded and explored the Titanic dataset.
2. Identified missing values.
3. Filled missing Age values using median.
4. Removed the Cabin column due to a large number of missing values.
5. Encoded Sex using label encoding.
6. Applied one-hot encoding to Embarked.
7. Removed unnecessary identifier columns.
8. Applied StandardScaler to Age and Fare.
9. Visualized outliers using boxplots.
10. Detected and removed outliers using the IQR method.

## Final Dataset
- Original rows: 891
- Final rows: 721
- Final columns: 10

## Files
- Task_1_Data_Cleaning_Preprocessing.ipynb
- Titanic_Cleaned.csv

## Conclusion
Successfully performed data cleaning and preprocessing on the Titanic dataset using Python libraries.
